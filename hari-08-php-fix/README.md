# Hari 08 - PHP (versi gabungan)

Gabungan folder `hari-08-php` dan `hari-08-php1`.

## Struktur

| Folder / file | Isi |
| --- | --- |
| `Lab1/dasar.php` | Lab 1 - PHP dasar |
| `Lab2/lab2.php` | Lab 2 - fungsi dan array asosiatif |
| `Lab3/bmi.php` | Lab 3 - kalkulator BMI (form + validasi) |
| `Lab4/` | `cari.php` (pencarian + log), `lihat-log.php`, `json-csv.php` |
| `fungsi_pendukung/` | `dev.php`, `lib-file.php`, `lib-peserta.php` (dipakai bersama) |
| `data/` | `peserta.json`, `peserta.csv`, `log.txt` |
| `proyek-4-buku-tamu/` | Proyek buku tamu |

| `arsip-draf-awal/` | Versi awal (sebelum dirapikan) dari `hari-08-php` |
